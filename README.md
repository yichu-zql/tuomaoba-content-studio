# 脱毛吧引流素材台

Ulike脱毛吧门店在 **抖音 / 小红书 / 视频号 / 朋友圈** 的引流创意库与素材工具。

- 每个平台按内容矩阵（门店体验、活动介绍、真实反馈和打卡、项目背书、门店指引和点位、科普答疑、福利与拉新）分主题，每个主题 6 条以上创意模板，左右翻页浏览。
- 每个主题最前面是“空白创意”：写下想法、选形式和卖点，生成完整创意（标题、封面、分镜/正文/朋友圈文案、要拍的门店图、合规检查）。
  - **快速生成**：从全部模板、团队改过的版本和保存的创意里，找同平台、同主题、同档期、同形式最接近的几条做骨架，再按你的想法改写钩子、卖点和活动信息；引号里的话（如“一次不到 4 块”）会直接用作标题和封面。
  - **用 Claude 生成**（仅在 claude.ai 打开时出现）：把最接近的模板一并发给 Claude 参考；用的是使用者自己的 Claude 额度，每人每 5 小时 10 次，从第一次使用开始计时，按钮上显示剩余次数和恢复时间。
  - 所有生成内容会自动替换禁用词，再做一次合规扫描。
- 点开任意创意可以直接改文字、上传本店照片替换封面、一键复制。
- 店名、位置、价格是变量，在“门店与价格”里改一次，全部文案同步。

## 文件
| 文件 | 内容 |
|---|---|
| `index.html` | 页面和样式 |
| `app.js` | 页面逻辑（筛选、翻页、编辑、合规扫描、门店图） |
| `gen.js` | 空白创意生成器（本地规则引擎；在 claude.ai 打开时可用 Claude 生成） |
| `base.js` | 门店变量、统一价格、门店图位、参考图、内容矩阵 |
| `content_douyin.js` 等 | 各平台创意模板 |
| `素材/` | 小程序页面参考图 |

## 发布到 GitHub Pages
仓库 Settings → Pages → Source 选 `Deploy from a branch`，Branch 选 `main` / `(root)`，保存后约 1 分钟生效。

## 说明
- 改过的文案、生成的创意、门店照片保存在各自浏览器里，可用“备份 / 导入”在同事之间传。
- 价格、活动规则以美团当期上架为准。
